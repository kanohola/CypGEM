# Dataset Overview

This directory contains the benchmark dataset used in our work, provided in the `dataset.sdf` file. 

### Key Details
* **Total Molecules:** The dataset consists of a total of 1,315 molecules.
* **Structural Variations:** Please note that some molecules within this dataset are stereoisomers or tautomers of the same parent compound. These variations are intentionally retained because even the same molecule can exhibit distinct physicochemical properties and electronic microenvironments in different conformations. Including these structural variations helps the model learn and capture these underlying chemical features more effectively.
